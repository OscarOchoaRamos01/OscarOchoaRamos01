## 🧑‍💻 Sobre mí

Me especializo en diseñar y desarrollar **soluciones backend empresariales** con Java y Spring Boot. Construyo APIs REST y arquitecturas de **microservicios** aplicando **Domain-Driven Design (DDD)**, **arquitectura hexagonal** y **programación reactiva con WebFlux**.

Me importa entregar software **seguro, escalable y mantenible**, con foco en calidad técnica (QA automatizado), metodologías ágiles (Scrum) y generación de valor real.

- 🔭 Actualmente trabajando en: microservicios con Spring Boot, Keycloak y Kubernetes
- 🌱 Aprendiendo: Cloud Native y Blockchain / Web3
- 🤝 Abierto a: oportunidades como Backend Developer o QA Automation, y a colaborar en proyectos
- 💬 Pregúntame sobre: Spring Boot, WebFlux, DDD, seguridad con JWT/OAuth2, testing y CI/CD
